
## The pillars of DevOps

**five areas**

### 1. reducing toil

- Toil consists of manual, repetitive, tactical, and automatable tasks that lack long-term value, such as manual server reboots, patching, or routine ticketing.
- Goal: Free up engineers from "grunt work" to focus on higher-value engineering tasks.
- DevOps Approach: Identify toilsome tasks, measure the time spent on them, and automate or eliminate them.

### 2. automation

- Automation is the foundational technology pillar, ensuring processes are consistent, reliable, and reproducible.
- CI/CD Pipelines: Automated build, test, and deployment reduce human error and speed up release cycles.
- Infrastructure as Code (IaC): Treating infrastructure configurations as code allows for automated provisioning and environment consistency.
- Toil Reduction: Automation specifically tackles the "toil" pillar by replacing manual intervention with self-healing systems and scripted procedures
