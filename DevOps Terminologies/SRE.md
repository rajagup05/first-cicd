
## SRE

SRE stands for Site Reliability Engineering. It is a discipline that applies software engineering mindsets to system administration and operations problems.

### 🏗️ How SRE Relates to DevOps

If DevOps is a philosophy or a set of values, SRE is the practical implementation of those values.
- DevOps: "We should reduce silos."
- SRE: "We will use a shared version control system and a common ticketing tool to bridge the gap."
